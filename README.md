# Ascendant Armor

A Fabric mod for **Minecraft 26.3** that adds **34 tiered armor enchantments** (11 core powers, 11 counters and a 12-enchant expansion) built for both PvP and PvE.
Dramatic particles and vanilla boss sounds (Warden roar, Ender Dragon growl, Wither spawn, thunder...) on every big ability.

| Tier | Color | Max level | Where it comes from |

## The enchantments (34)

Three sets. The **Core** set is the power fantasy; the **Counter** set gives every core mechanic an answer (with lower numbers and immunities only at top level, so no single build dominates); the **Expansion** set adds offense, utility and PvE tools. Only four enchants are active (one per piece: Z / X / C / V); everything else is passive.

## Balance matrix

| Core power | Answered by | How |
|---|---|---|
| Warden's Roar | Sculk Ward | Cuts sonic damage and debuff time 15/30/45% |
| Predator's Sight | Shadowveil | I: seen only within 8 blocks; II+: immune to Glowing, sneak-stealth |
| Wither's Wrath | Witherbane | Cuts Wrath damage and drain 20/40/60%; III cleanses Wither |
| Vampiric Pact / life-drain | Anathema | Cuts lifesteal 25/50/75% and hurts Vampiric attackers |
| Burst damage / one-shots | Bastion | Survive a killing blow at 1 heart if above 60% / 45% health (30s / 20s cooldown) |
| Dragon's Dash, knockback | Rooted | Cuts knockback 25/50/75%; III is immune to Levitation |
| Phantom Stride | Truestrike | Reduces the target's dodge chance 5/10/15% |
| Kiting (Dash, Skybound, Speed) | Hamstring | Melee hits Slow; III is Slowness II + Weakness |
| Emberstride, fire | Glacial Stride | Extinguishes; II ignition immunity; III chill aura |
| Earthshatter, shockwaves, lightning | Tremorguard | Cuts shockwave/lightning damage 20/40%; small falls harmless |
| Hit-and-run play | Meditation | Regeneration while standing still (2s) |

### Nerfs this round
- **Voidstep** and its counter **Voidlock** are removed. **V** now fires **Skybound**.
- Counters: lower percentages across the board (Sculk Ward 15/30/45, Witherbane 20/40/60, Anathema 25/50/75, Rooted 25/50/75, Truestrike 5/10/15, Tremorguard 20/40, Bastion needs more health to trigger and has a longer cooldown).
- Fewer free immunities: Darkness immunity (Sculk Ward), Wither/Hunger cleanses (Witherbane), Levitation/Slowness immunity (Rooted) and Glacial Stride's fire immunity were pushed to higher levels or removed.
- Defensive core: Retribution 15/30/45% (max 8 reflected, was 25/50/75% max 12). Phantom Stride 6/12/18% dodge with a 1s internal cooldown (was 10/20/30%).

## Hotkeys

| Key | Fires |
|---|---|
| **Z** | Helmet ability (Warden's Roar) |
| **X** | Chestplate ability (Wither's Wrath) |
| **C** | Leggings ability (Dragon's Dash) |
| **V** | Boots ability (Skybound) |

Rebind in *Options > Controls > Key Binds > Ascendant Armor*. Keys just send `/ascendant use <slot>` to the server, so the mod must be installed on the server too.

## Commands

| Command | What it does |
|---|---|
| `/ascendant list` | Lists every enchant with tier and slot |
| `/ascendant use helmet\|chest\|legs\|boots` | Fires that piece's active (this is what the hotkeys do) |
| `/ascendant kit [core\|counter\|expansion]` | **Cheat:** full netherite set. No argument = all 34 enchants, `core` = 11 offensive, `counter` = 11 answers, `expansion` = the 12 extras (great for testing fights between two kits) |
| `/ascendant book <enchant> [level]` | **Cheat:** gives an enchanted book |

Cheat commands only work in singleplayer unless you set `CHEAT_COMMANDS_EVERYWHERE = true` in `AscendantMod.java`. On servers use vanilla `/enchant @s ascendant:warden_roar 2`.

## Install (players)

1. Install Minecraft **26.3**, **Fabric Loader 0.19.5+**, and **Java 25**.
2. Drop **Fabric API for 26.3** and the Ascendant Armor jar into your `mods` folder.

## Build

### GitHub Actions (recommended)
Push to `main`. The workflow in `.github/workflows/main.yml` builds the jar with JDK 25 + Gradle 9.6.0 and uploads it as the **ascendant-armor-jar** artifact (Actions tab > latest run > Artifacts).

### Locally
Requires JDK 25 and Gradle 9.6+:

```
gradle wrapper --gradle-version 9.6.0   # one time, generates ./gradlew
./gradlew build
```
The jar lands in `build/libs/`.

## Editing the enchants

`tools/generate.py` is the single source of truth for names, tiers, slots, costs and lang strings. After editing it, run:

```
python3 tools/generate.py
```
That regenerates `Ench.java`, the enchantment JSON files, the loot/table tags and the language file. Ability behavior lives in `Actives.java`, `Passives.java` and `Combat.java`.

## Tuning

Everything is plain numbers in the Java files (damage, radius, cooldown ticks). Cooldowns are in ticks (20 = 1 second).
